#  Keywords & Definitions

| Keyword | Definition |
| :--- | :--- |
| **For Loop** | Executes a code block a specific number of times (counted iteration). |
| **While Loop** | Executes a code block repeatedly until a specified condition is no longer met. |
| **List** | A built-in data structure used to store an ordered collection of items under a single variable name. |
| **Function** | A named, reusable block of executable code designed to perform a specific task. |
| **Parameter** | A variable placed inside the function definition that acts as a placeholder for incoming data. |
| **Argument** | The actual data value passed to a function when it is called. |
